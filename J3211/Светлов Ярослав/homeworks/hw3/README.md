# ДЗ3 — CSS-переменные и темы

Node.js 22+. Установка: `npm ci`. Запуск: `npm start`, адрес http://localhost:3003.
Тесты: `npm test`. Аккаунты: `admin@nexus.ai`, `alex@nexus.ai`; пароль `password`.
Светлая или тёмная тема выбирается по настройке системы. Рабочая база — `db.local.json`.
